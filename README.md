# Weather App

A responsive weather app built with React. Search for any city to see the current weather and a 7-day forecast.

**Live demo:** [https://weather-app-alphatech.vercel.app/]



## Features

- Search for any city
- Current temperature and conditions
- 7-day forecast
- Loading and error states
- Responsive design for phone, tablet and desktop

## Built with

- React
- Vite
- [Open-Meteo API](https://open-meteo.com/) (no API key needed)
- CSS (flexbox and media queries)

## Run it locally

```bash
git clone https://github.com/Tumelo-Tutubala/weather-app.git
cd weather-app
npm install
npm run dev
```
